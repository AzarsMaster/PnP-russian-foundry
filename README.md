# Бродяги и Бесподобные — русский перевод

Модуль для **Foundry VTT 13 и 14**, система **Prowlers and Paragons** (`prowlers-and-paragons`) версии **2.0.0–2.0.1** от [csheepy](https://github.com/csheepy/prowlers-and-paragons-fvtt).
Система 2.0.1 заявляет совместимость с Foundry 13 и 14.364. Старая система от syntruth не поддерживается.

Перевод охватывает листы персонажей, Миньонов, транспорта, штаб-квартиры и Мастера игры, листы предметов, диалоги бросков и противостояний, результаты и кнопки бросков в чате, меню переброса и настроек системы.
Термины взяты из [глоссария](docs/glossary.md): **Мощь, Прочность, Инициатива, Решимость, Очки Героизма**. [Переводческие решения](docs/translation-notes.md) объясняют неоднозначные места.

В комплекте **Roboto** с кириллицей, курсивом и весами 100–900. Сетевые запросы к Google Fonts не требуются.

## Установка

1. Установите Foundry VTT 13 или 14 и систему Prowlers and Paragons 2.0.1. Для работы системы нужен **socketlib** — это её собственная зависимость.
2. На стартовом экране Foundry откройте **Модули → Установить модуль**, вставьте в поле **Manifest URL / URL манифеста** ссылку ниже и нажмите «Установить».
3. Откройте мир Prowlers and Paragons и включите модуль «Бродяги и Бесподобные — русский перевод» в управлении модулями.
4. Выберите **Русский** в настройках языка Foundry и перезагрузите страницу.

Перевод включается только для русского языка и нужной системы. Roboto включён по умолчанию; его можно отключить в настройках модуля.
Для перевода остального интерфейса самой Foundry используйте отдельную русскую локализацию ядра.

В **0.2.0** добавлены тёмная, светлая и зелёная темы. После обновления модуля перезагрузите страницу мира (`Ctrl+F5`).

Рабочая ссылка установки:

```text
https://github.com/AzarsMaster/PnP-russian-foundry/releases/latest/download/module.json
```

Для ручной установки скачайте `pnp-russian.zip` из [Releases](https://github.com/AzarsMaster/PnP-russian-foundry/releases/latest) и распакуйте в `Data/modules/`, затем перезапустите Foundry. Должен получиться путь `Data/modules/pnp-russian/module.json`.

В поле URL манифеста нужен прямой JSON по ссылке выше. Страница репозитория, страница GitHub с просмотром файла и архив исходников **Code → Download ZIP** для этого поля не подходят.

## Цвет листов

Откройте **Настройки → Настроить параметры → Бродяги и Бесподобные — русский перевод**.

| Настройка | Кто выбирает | Действие |
|---|---|---|
| **Тема листов — для всего мира** | Мастер | Общая тёмная, светлая или зелёная тема; по умолчанию светлая. |
| **Тема листов — личная** | Каждый пользователь, включая мастера | «Как у мастера» либо собственная тёмная, светлая или зелёная тема. |

Личный выбор имеет приоритет над общей темой и сохраняется в профиле пользователя этого мира, включая вход из другого браузера. Настройки другого пользователя не меняются. Вариант **«Как у мастера»** возвращает общую тему и следует её дальнейшим изменениям.

Изменения сразу применяются к уже открытым и новым листам PnP — персонажам, другим типам персонажей и предметам. Чат и остальные окна Foundry не перекрашиваются. Roboto и перевод сохраняются.

## Что изменяет модуль

Стандартные ключи локализации дополняются русским каталогом. Для английских надписей, зашитых в шаблоны системы, используются обработчики отображения листов, диалогов и карточек бросков. Динамические списки переводятся после их появления.

Имена персонажей и предметов, пользовательские описания и тексты, формулы `dp`, числовые результаты и игровые документы не изменяются. Модуль не переводит содержимое книг или компендиумов и не добавляет новые правила бросков. Универсальные окна Foundry и уведомления, которые система выводит прямо на английском (например, об отсутствии цели, таймауте противостояния или применённом Уроне), остаются английскими. В сообщениях о расходе ресурсов остаётся слово `spends`. Глобальная подмена API не применяется.

Особенность системы 2.0.1: некоторые расчёты оружия и Брони находят предметы по английским именам `Martial Arts` и `Armor`. Сохраняйте эти имена механических предметов: их переименование может повлиять на броски независимо от локализации интерфейса.

Не включайте одновременно другой перевод этой же системы: одинаковые ключи будут зависеть от порядка загрузки модулей.

## Разработка и проверка

Требуются Node.js 22+ и утилита `zip`. В рантайме Foundry Node-зависимости модуля не нужны.

```sh
cd /workspace/PnP-russian-foundry
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

Браузерная проверка со стилями системы 2.0.1:

```sh
npx playwright install chromium
npm run test:browser
```

Если Chromium уже установлен, можно указать путь: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`.

Результат: `dist/pnp-russian.zip`, `dist/module.json`, `dist/SHA256SUMS`.
Тесты проверяют перевод на шаблонах системы, подстановки, DOM, сохранность пользовательского содержимого и подключение обработчиков для API Foundry 13/14.
Они не заменяют запуск лицензированной Foundry. Финальная ручная проверка в обеих версиях описана в [docs/testing.md](docs/testing.md).

Процесс GitHub Actions проверяет код и отображение в Chromium, собирает архив и публикует релиз при отправке тега `v0.2.0` (версия тега должна совпадать с `module.json`).
