# Результаты проверки текущей сборки

Проверено в облачной среде разработки:

- `npm run check`: манифест, пути, JSON, синтаксис скриптов, локальные WOFF2.
- `npm test`: 28 проверок; все прошли, пропусков нет. Рендер реальных шаблонов всех типов листов системы, диалогов и чата; соответствие 154 английским ключам, подстановки, сохранность имён/данных/обработчиков, динамические списки, модель Hooks для поколений 13 и 14.
- Chromium: модули ES загрузились без ошибок; Roboto применяется к русским подписям, загружаются кириллица, жирное и курсивное начертания; шрифт иконки не подменён; наблюдатель переводит новые варианты броска в реальном DOM.
- `npm run build` и `zip -T dist/pnp-russian.zip`: архив собран и прошёл проверку целостности.

Исходники шаблонов: `csheepy/prowlers-and-paragons-fvtt`, релиз 2.0.1 и main `b073524`; точные ссылки находятся в `tests/fixtures/upstream/README.md`.

Foundry VTT 13 и 14 в этой среде не запускались. Лицензированное ядро, socketlib, сетевые противостояния между игроками и полная игровая сессия здесь не проверены. Инструкция для такой приёмки: [testing.md](testing.md).

GitHub Release не опубликован; ссылка установки через манифест станет доступна после публикации архива и `module.json`.
