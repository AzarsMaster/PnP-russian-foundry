# Результаты проверки текущей сборки

Проверено в облачной среде разработки:

- `npm run check`: манифест, пути, JSON, синтаксис скриптов, локальные WOFF2.
- `npm test`: 41 проверка; все прошли, пропусков нет. Добавлены регрессии для событий конкретных классов листов, внутренней формы и внешнего окна, повторного рендера, уже открытых листов и вставки окна без общих событий Application. Также проверены все типы шаблонов, 154 ключа, подстановки и сохранность пользовательских данных.
- `npm run test:browser`: Chromium, исходные стили PnP 2.0.1, оба порядка загрузки CSS. Проверены перевод вкладок, обнаружение нового окна без событий, Roboto в 11 селекторах (включая заголовки таблиц, поля и редактор), кириллица, жирное и курсивное начертания, сохранение шрифта иконок и пользовательских текстов. Внешние запросы к Google Fonts заблокированы во время проверки.
- `npm run build` и `zip -T dist/pnp-russian.zip`: архив собран и прошёл проверку целостности.

Исходники шаблонов: `csheepy/prowlers-and-paragons-fvtt`, релиз 2.0.1 и main `b073524`; точные ссылки находятся в `tests/fixtures/upstream/README.md`.

Foundry VTT 13 и 14 в этой среде не запускались. Лицензированное ядро, socketlib, сетевые противостояния между игроками и полная игровая сессия здесь не проверены. Инструкция для такой приёмки: [testing.md](testing.md).

Релиз 0.1.0 опубликован и доступен. Обновление 0.1.1 исправляет подключение к листам и перекрытие шрифтов системы. Состояние публикации новой версии проверяется по GitHub Actions и публичному манифесту; локальная сборка сама по себе публикацию не подтверждает.
